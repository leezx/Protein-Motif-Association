# PMA 项目身份

- **项目：** Protein–Motif Association（PMA）。
- **正式目标：** 发布人类 protein–motif genomic association reference，以可追溯的 ChIP 占据证据和经去冗余的 motif 库为基础，报告匹配基因组背景下的关联、同一 biosample 内的 protein specificity、HOT 区域控制和独立复现。
- **100% 定义：** 以 [`docs/PROJECT_CHARTER.md`](../docs/PROJECT_CHARTER.md) Part 1 为准；包括 association matrix、证据分级及基于真实计算的 Figure 1/2。UDE 不重新定义验收标准。
- **边界：** 这是关联资源，不是招募机制的因果研究。原始及计算所得数据位于仓库外的 `DATA/2.PROJECTS/PMA/`；仓库保存代码、合同、manifest 和小型摘要。
- **规范来源：** [`README.md`](../README.md)、[`docs/PROJECT_CHARTER.md`](../docs/PROJECT_CHARTER.md)、[`design/PMA_pseudo_figures_v0.2.md`](../design/PMA_pseudo_figures_v0.2.md)。后者在 README 中标为冻结设计；v0.1 仅作历史材料。
- **UDE 角色：** 这里是状态和来源索引。`docs/` 与 `design/` 中的正式合同、`Worklog.md` 和 `docs/handoff/` 继续保留原路径及权威性。
